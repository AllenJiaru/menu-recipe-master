## 📏 图片规格建议

- **格式**：PNG（推荐）或 JPG
- **分辨率**：1080 x 1920（竖屏）或 1920 x 1080（横屏）
- **文件大小**：< 500KB（建议压缩）
- **命名规范**：使用小写字母和下划线，如 `role_select_page.png`
